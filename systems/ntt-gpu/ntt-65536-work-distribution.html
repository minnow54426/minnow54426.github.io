2. How GPU threads share the work

A GPU runs many threads together. A block is a team of threads that can share fast temporary memory. Within a transform stage, each butterfly updates a different pair of values, so the pairs can run in parallel.

Picture 65,536 values arranged as 256 rows of 256. In the forward transform, blocks first work down columns for eight stages, then across rows for eight more. At stage 1, block 0, thread 0 updates positions 0 and 32,768. Change the thread to 1 and see which two positions move.
