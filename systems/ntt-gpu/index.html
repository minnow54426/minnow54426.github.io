New to the project?

CKKS is an encryption scheme that allows calculations on encrypted data. It represents data using polynomials. OpenFHE is the cryptography library we aim to integrate with. The Number Theoretic Transform (NTT) changes how a polynomial is represented so multiplication becomes easier. This project first aims to run that transform efficiently on a GPU.

  1. Learn the NTT and butterflies with small numerical examples.
  2. See how the GPU divides the work, then trace one thread in the 65536-point explorer.
  3. Read the measured results or build the project.
Useful words before you start
  • Modulo q: keep the remainder after division by q. For example, 20 modulo 17 is 3.
  • Coefficient: a number multiplying a power of x in a polynomial. An evaluation is the value obtained by substituting a point for x.
  • Tower: one polynomial represented under one prime. Several towers represent its coefficients under several primes.
  • Host / device: the CPU and its memory / the GPU and its memory. An upload copies host data to the device; a download copies it back.
  • Kernel / stream: a function executed by GPU threads / an ordered queue of GPU work.
  • Fixture / oracle: repeatable test inputs / a separate calculation used to check the answers.
  • Native check: a test that actually runs on the target hardware. Compiling CUDA alone does not run a GPU test.
  • Gate: a required check before work can be called complete. D labels a working milestone and P labels a phase.
