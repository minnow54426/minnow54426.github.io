A roadmap with explicit gates¶

Reconstructed on 2026-11-08 from the linked commits and reports.

Outcome¶

Added the 95-working-day integration plan, GPU selection survey, and clearer implementation naming and formatting.

Reasoning¶

The sequence is NTT, base conversion, Hybrid key switching, then OpenFHE. Each step needs its own exact-answer and performance checks before it can be called complete. Running an encrypted inference model comes after the OpenFHE integration. RTX 5090 is the provisional primary target and RTX 4090 the control; the hardware report requires workload-specific benchmarks before claiming a winner.

Changes¶

  • Roadmap and hardware survey.
  • Readability changes.
  • Tracked plan.

Verification¶

The plan separates the CPU/OpenFHE baseline from the first real GPU gate. No new GPU timing is recorded here.

Open questions¶

The design still needs to specify what each stored number means, its array position, who owns each buffer, and the order of OpenFHE operations.

Next step¶

Map the forward column kernel's indices and memory accesses for N=4096 and N=65536.
