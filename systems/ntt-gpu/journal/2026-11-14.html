This is the reported identity, not an independently verified board specification. It is neither the primary RTX 5090 nor the planned RTX 4090 control; record the run as an additional Ada diagnostic. No primary-device gate advances.

The completed collector reports GPU_CHECKS_PASSED. All 23 CTests passed, including all four registered native GPU gates; all four sanitizer smoke tools passed. Raw logs and the report have been copied back to the local workspace.

Follow-up: analyze the exported native evidence offline¶

The user reports the rental is stopped. No reconnection, billing action or new GPU execution was performed during this analysis.

Outcome and reasoning¶

Added the first-run analysis. Correctness evidence is strong for the tested arrays, but performance evidence is one averaged 46-bit/K=3 row. There is no measured bottleneck, optimized OpenFHE CPU timing, kernel-only breakdown or production inference speedup. P2 and B04 remain open.

Audited the 169,279,488-comparison count: 63 pattern/basis combinations, 41 towers summed across nine basis groups, seven patterns and nine equality checks per residue position. It is not 169 million independent random cases. Each sanitizer covers two patterns/three towers, not the full basis matrix.

The benchmark's approximately 60.35× forward ratio is against this repository's scalar reference only. Source inspection found missing dedicated inverse warm-up/reset, different CPU/GPU forward repetition input policies, host-copy costs inside multiply timing, and no saved individual samples. These are measurement limitations to fix in a separate implementation task, not evidence that the executed exactness tests or means are fabricated.

Transfer accounting confirms 9S versus 3S operand traffic for separate versus fused public multiplication, with eight launches in either case. That supports the device-resident architecture, but summing unmatched means does not measure a fusion speedup. Arithmetic cost, 2,048-byte column-thread strides, partial butterfly-thread participation and host copies are profiling hypotheses only.

Follow-up: implement offline measurement and setup-failure preparation¶

Outcome¶

Implemented the offline tooling increment: raw public-call timing protocol, strict JSONL validation, a shared setup allocation owner, host fault tests and a prepared native constructor probe. No connection to the stopped rental was made. The new CUDA code is uncompiled/unrun here; the successful native record above applies only to 19cc285, not these changes. No working-day or native gate is marked complete.

Reasoning and changes¶

Used one ownership seam for the production CUDA constructor and the host test adapter, rather than implementing a separate cleanup algorithm in tests. SetupResources tracks the actual six allocations and four constant uploads; host tests cover failures before adapter calls and adapter exceptions, reverse cleanup, and cleanup-failure accounting. The GPU-labelled cuda_setup_fault_injection constructs the real wrapper and checks real CUDA frees after synthetic pre-call failures. It is prepared, not executed.

bench-jsonl uses parameter files for exact N/q/root identity and deterministic seeded operands. Each operation has fixed-input reset and explicit warm-up; reset/packing is outside timing. It measures scalar reference forward, public GPU forward, inverse, pointwise, unfused product and fused product. It saves all samples and linear-interpolated percentile summaries. Fused output is now retained/released outside timing; its by-value input allocation/copy remains inside the public call. Legacy bench stays available for reproducing old rows.

The collector now requires the new native setup probe and new host gates; benchmark mode generates 50/55/60-bit parameters and retains three JSONL logs. It recomputes summaries and rejects truncated, malformed, wrongly scoped, incomplete or explicitly synthetic data even after a zero executable exit. Tooling mocks remain labelled synthetic/control-flow evidence, not GPU results. The parameter generator now accepts an optional bit-width argument.

Updated the D5 ownership map/static checks, collector instructions and backlog. The mathematical NTT kernels and modular arithmetic algorithms are unchanged.

  • measurement_json_interop compiled the C++ JSON writer and validated its explicitly synthetic six-operation output with the Python parser.
