Outcome¶

The documentation now builds into one website. It has shared navigation, search, a homepage showing current progress, and a daily journal. Readers can still use the interactive lessons.

Reasoning¶

Developers need stable explanations and the history behind decisions. Research stays in reference articles; each journal entry records changes, evidence, decisions, and unresolved questions.

Edit the Markdown source and generate the HTML website from it, so there are no separate text copies to maintain. Existing interactive HTML keeps its controls and equations. Entries written later from old records say that they are reconstructed. Journal dates are calendar dates; roadmap D labels are working milestones.
