4. Keep intermediate values on the GPU

The host is the CPU and its memory. The device is the GPU and its memory. A resident operation keeps its working arrays on the device. For polynomial multiplication, the GPU can run both forward transforms, the pointwise product and the inverse transform after a single upload of each input. Only the final result needs to come back.

Step through the same multiplication with both patterns below. Count how many full polynomials cross the boundary. Moving fewer bytes can help latency, which the benchmark measures separately.
